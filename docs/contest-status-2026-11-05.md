# 점심 빙고 개발 결과와 공모전 확인 사항

기준일: 2026년 11월 5일

점심 빙고의 구현·배포 결과와 BC카드 AI 서비스 수익화 챌린지 참가 전에 확인할 사항을 정리한다. 서비스는 배포되어 있으나, 공식 신청 페이지 접속 문제로 이번 작업에서 참가 신청과 약관 확인을 마치지 못했다. 이를 참가 불가나 미등록 확정으로 해석해서는 안 된다.

## 서비스와 구현 결과

- 서비스: [점심 빙고](https://indosaram.github.io/lunch-bingo/)
- 소스: [Indosaram/lunch-bingo](https://github.com/Indosaram/lunch-bingo)
- k-skill의 `bccard-eatpl-search`를 이용해 동네별 식당을 조회하고, 점심시간 조건과 업종 필터를 통과한 매출 순위 상위 24곳으로 5×5 빙고판을 만든다.
- 같은 동네·같은 달에는 동일한 판을 제공한다. 방문 도장은 브라우저의 `localStorage`에 저장하고 진행 상황을 링크로 공유할 수 있다.
- 현재 빌드는 18개 동네를 포함한다. 검색은 주소 부분 일치 기반이며 도보 거리나 반경 검색이 아니다. 영업시간도 결제 시각을 바탕으로 한 추정치이므로 실제 방문 전 확인이 필요하다.

구조와 실행 방법은 [README](../README.md)에 정리되어 있다.

## 수정과 검증

검증 대상 커밋은 [d64afc678e14c22ede8cbc80a6ade2adeb383163](https://github.com/Indosaram/lunch-bingo/commit/d64afc678e14c22ede8cbc80a6ade2adeb383163)이다.

- 시·도와 시·구를 대조해 동명이인 지역이 섞이는 문제를 수정했다. 잠실 판은 서울 송파구 주소만 허용한다.
- 매월 판의 매장·위치를 유지하고, 잘못 포함된 매장만 교체하도록 변경했다.
- 도장을 월·동네별로 분리하고 기존 저장 데이터의 이관 및 매장별 방문 기록 보존을 추가했다.
- 잘못된 API 응답, 기존 판 읽기 실패, 식당 수 부족 시 불완전한 사이트를 배포하지 않고 빌드를 실패시키도록 했다.
- [GitHub Actions 실행 41974201203](https://github.com/Indosaram/lunch-bingo/actions/runs/41974201203)에서 Python 21개와 JavaScript 15개, 총 36개 회귀 테스트가 통과했다. JavaScript 문법 검사, 18개 동네 빌드, Pages 배포도 성공했다.
- 배포 후 잠실 판 점검에서는 24곳 모두 송파구 주소였다. 이는 해당 시점의 주소 검증 결과이며 전체 매장 정보의 정확성을 보장하지는 않는다.

회귀 테스트는 합성 데이터와 모의 네트워크를 사용한다. 실제 API 연결과 배포는 별도 빌드 단계에서 확인했다.

## 남은 품질 확인 사항

- 업종 필터는 원천 API의 업종명을 사용한다. 카페가 다른 업종으로 분류되는 등 원천 분류가 실제 업태와 다르면 점심 식당 후보에 남을 수 있어 추가 검증이 필요하다.
- 검색 응답에서 빠진 기존 매장은 바로 폐업으로 처리하지 않고 마지막 표시 값을 유지한다. 상세 화면의 매장별 갱신일을 함께 확인해야 한다.
- 36개 테스트와 잠실 점검만으로 모든 동네의 실제 영업 여부, 메뉴, 도보 접근성까지 확인한 것은 아니다.

## 공모전 일정과 현재 확인 상태

[대학내일의 공모전 담당자 명의 안내](https://www.univ20.com/Community/Detail/2243?pageidx=2)와 [2026년 11월 3일 뉴시스 보도](https://www.newsis.com/view/NISX20261103_0003852443)는 다음 일정을 구분한다.

- 참가·서비스 등록 마감: **2026년 12월 3일**
- 챌린지 진행 종료: **2026년 12월 13일**

뉴시스 보도에는 등록 이후 발생한 잇플 유입 실적부터 평가에 반영된다고 설명되어 있다. 12월 13일을 등록 마감으로 해석하면 안 된다. 정확한 마감 시각과 최종 조건은 공식 안내에서 재확인해야 한다.

[공식 신청 페이지](https://edu.bccard.ai/contest)는 2026년 11월 5일 14:35 KST를 포함한 확인 시도에서 `Site Unavailable`로 표시되었다. 이 접근 결과만으로 사이트의 전면 장애나 공모전 종료를 단정할 수는 없다.

이번 작업에서는 신청서 제출이나 약관 동의를 수행하지 않았다. 기존 등록 여부를 증명하는 접수 확인 자료도 확보하지 못했으므로 **등록 상태는 미확인**이다.

## 참가 전에 확인할 사항

1. 공식 신청 페이지에서 기존 접수 내역과 등록 요건을 확인하고, 필요한 경우 제출 후 접수 확인 자료를 보관한다.
2. 공식 약관 원문에서 API 이용, 데이터 보관·갱신·공개, 출처 표기 조건을 확인한다. 저장소의 구현 설명이나 코드 주석은 공식 약관 검증을 대신하지 않는다.
3. 잇플 유입 집계 방식, 등록 도메인·URL, 활성 사용자 인정 조건을 확인한다. 현재 링크 구조만으로 실적 인정 여부를 보장할 수 없다.
4. 원천 업종 오분류와 실제 점심 영업 여부를 추가 점검한다.

현재 구현은 API가 반환한 `merUrl`을 변경하지 않고 링크로 열며, 빌드에서 상세 페이지를 호출하지 않는다. 원본 API 응답 전체를 저장·누적하지 않고 화면 표시용 값과 현재 공개 판을 이용한다. 이는 [현재 코드와 README](https://github.com/Indosaram/lunch-bingo/tree/d64afc678e14c22ede8cbc80a6ade2adeb383163)의 동작 설명이며, 공식 약관 준수 또는 위반에 대한 결론은 아니다.

공모전 참가가 진행되지 않더라도 현재 서비스, 소스 코드, 회귀 테스트와 이 문서는 후속 개발의 출발점으로 남길 수 있다.
